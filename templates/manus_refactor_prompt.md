# Prompt-modelo para usar com Manus IA

Use a skill `vida-layout-refactor` para refatorar o layout deste aplicativo.

Objetivo: tornar a interface mais profissional, limpa, menos poluída visualmente e compatível com a identidade visual da Vida Hematologia / Vida Pesquisa Clínica, preservando integralmente a lógica de negócio, dados clínicos, cálculos, rotas, integrações e fluxos existentes.

Antes de modificar o código:
1. Identifique a stack e a estrutura do projeto.
2. Localize arquivos globais de estilo, tema, componentes e layout.
3. Audite as telas principais e liste os problemas de UI/UX.
4. Proponha um plano curto de refatoração.

Durante a implementação:
1. Centralize design tokens de cor, tipografia, espaçamento, borda, raio e sombra.
2. Padronize botões, cards, inputs, badges, tabelas, modais, headers e sidebars.
3. Use a paleta da Vida Hematologia com base neutra, vermelho institucional como destaque e teal para pesquisa clínica.
4. Reduza poluição visual: menos cards, menos cores, menos bordas, menos sombras e melhor hierarquia.
5. Mantenha uma estética médica, institucional, técnica e premium.
6. Preserve a funcionalidade existente.

Ao final:
1. Informe arquivos alterados.
2. Explique decisões de design.
3. Liste limitações e próximos refinamentos recomendados.
4. Execute testes/build/lint quando disponíveis.
