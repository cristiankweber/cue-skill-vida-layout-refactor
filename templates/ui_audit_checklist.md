# Checklist de auditoria visual e UX

Use este checklist antes e depois da refatoração.

## Diagnóstico inicial

- [ ] A tela tem uma ação principal clara?
- [ ] O usuário entende a finalidade da tela em até 5 segundos?
- [ ] Existem cores demais competindo?
- [ ] O vermelho institucional está sendo usado com moderação?
- [ ] Há excesso de cards, bordas, sombras ou badges?
- [ ] Existem textos repetidos ou rótulos longos demais?
- [ ] A navegação está simples?
- [ ] O espaçamento entre blocos está consistente?
- [ ] Há componentes duplicados ou estilos criados manualmente?
- [ ] A interface parece institucional e médica?
- [ ] O contraste do texto está adequado?
- [ ] Botões primários e secundários estão claramente diferenciados?
- [ ] Formulários têm labels claros e seções lógicas?
- [ ] Tabelas são legíveis?
- [ ] A responsividade foi considerada?

## Pontos de refatoração prioritários

1. Criar ou ajustar tokens globais de design.
2. Unificar botões.
3. Unificar cards.
4. Unificar inputs e selects.
5. Padronizar tabelas.
6. Simplificar navegação.
7. Reduzir densidade visual.
8. Melhorar hierarquia dos títulos.
9. Aplicar a paleta institucional.
10. Validar acessibilidade e responsividade.

## Pós-refatoração

- [ ] A lógica do sistema foi preservada.
- [ ] Não houve remoção acidental de campos clínicos.
- [ ] Componentes reutilizáveis foram melhorados.
- [ ] A tela ficou mais limpa.
- [ ] A marca está reconhecível sem exagero.
- [ ] O código ficou mais fácil de manter.
- [ ] Há consistência entre telas.
- [ ] O layout está adequado para uso profissional em saúde.
